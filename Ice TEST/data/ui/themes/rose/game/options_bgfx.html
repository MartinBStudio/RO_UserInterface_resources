Loot Filter

Type exact drop names, separated by commas. Matching drops get that colour, a glow and a bigger label.

How it works

Exact names: type the name exactly as it shows on the ground, including capitals and spaces (for example Purple Powder, not purple powder).

Colours: the lists follow item rarity, from Yellow (normal) up to Green, with Rainbow on top. If a name is in two lists, the rarer colour wins.

After Save, restart the game to update which drops glow. The two checkboxes work right away.

Keep Game > Show dropped item name switched on. When the game hides drop names, it also stops updating them, so the filter has nothing to work with. Use Only show filtered drops instead to hide the other names.

Only show filtered drops hides every other drop name. Dim other drops shows them at half strength instead. Both do nothing while all lists are empty.

Profiles: Save as profile stores the boxes under a name. Click a profile to switch to it: instant for profiles saved before this game session, a new or changed profile needs one restart first. Save also updates the highlighted profile. Delete removes it.

Clear all empties the boxes; press Save to keep that. Your lists are stored in loot_filter.txt in the game folder.

 Add-ons

Target Bar

Target Marker

Colour of the arrows next to a selected player's name. Restart the game after changing it.

Other extras

Loot Filter (tab above): glowing names and loot beams for chosen drops, profiles, dim or hide other drops.

Target bar: the target's element and the elements it is weak against, plus a DPS meter (switches above).

Party and group windows: the FX button turns the stun / poison / slow frames on member portraits on or off (purple = on).

Item Mall: click an item to try it on straight away in the preview.

Inventory: the small button left of the X collapses the window.
