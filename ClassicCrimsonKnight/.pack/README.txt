CLASSIC CRIMSON KNIGHT  (version 1.0.0)
=======================================
Classic pre-Evolution windows in knightly crimson, with ruby buttons and yellow selected tabs.

From ROSE Online Toolbox: https://roseonlinetoolbox.com/mods?mod=classic-crimson-knight

Only one UI theme at a time: install another straight over the top.

INSTALL
    Copy the data folder into your ROSE Online folder.
    Every file it installs is listed in .pack\FILE_LIST.txt.

UNINSTALL
    Delete those files. The game falls back to its stock UI.

FILES
    data\ui\themes\rose\imgs\rtb-premium-classic-crimson-knight.dds
    data\ui\themes\rose\styles\window.css

This theme replaces whole UI files. After a game patch, check the
toolbox for an updated version so you do not miss official UI fixes.
