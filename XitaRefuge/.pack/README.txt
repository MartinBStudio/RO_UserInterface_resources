XITA REFUGE  (version 1.3.1)
============================
Canvas-and-timber camp colors with warm lantern light.

From ROSE Online Toolbox: https://roseonlinetoolbox.com/mods?mod=xita-refuge

Only one UI theme at a time: install another straight over the top.

INSTALL
    Copy the data and res folders into your ROSE Online folder.
    Every file it installs is listed in .pack\FILE_LIST.txt.

UNINSTALL
    Delete those files. The game falls back to its stock UI.
    RO Toolbox puts the stock cursors (res\*.cur) back from .default. By hand,
    copy them back instead, or install Default Cursors from the toolbox.
